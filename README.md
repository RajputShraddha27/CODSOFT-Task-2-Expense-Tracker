# Expense Tracker

A modern and responsive Expense Tracker application built with React.

It allows users to manage their income and expenses, track their current balance, filter transactions, and store data locally in the browser.

## Live Demo

[View Live Project](https://codsoft-task-1-expense-tracker.netlify.app/)

## Features

- Add income and expense transactions
- Edit existing transactions
- Delete transactions with confirmation modal
- Calculate total income
- Calculate total expenses
- Calculate current balance
- Filter transactions by category
- Filter transactions by transaction type
- Form validation
- LocalStorage support
- Dark Mode / Light Mode
- Responsive design
- Smooth scrolling when editing a transaction
- Toast notifications for successful actions
- Professional and responsive UI

## Technologies Used

- React
- JavaScript
- Bootstrap
- CSS
- React Icons
- React Toastify

## Transaction Features

Users can add:

- Transaction Type
- Title
- Amount
- Category
- Date

Available categories:

- Salary
- Food
- Shopping
- Travel
- Entertainment
- Bills
- Health
- Other

## Dark Mode

The application includes a Dark Mode feature.

The selected theme is stored in LocalStorage, so the user's theme preference remains saved after refreshing the page.

## Data Storage

Transactions are stored in the browser using LocalStorage.

This means transactions remain available after refreshing the page.
